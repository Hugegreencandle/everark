EverArk — Distributed Resurrection

Byte-exact state recovery from independent Evernode hosts after host loss.
✓
byte-exact ✓
EverArk rebuilt a live application's state byte-for-byte from a k-of-n subset of shards held on genuinely independent, third-party Evernode hosts, after the remaining hosts were gone. The recovered state's canonical root equals the anchored root.

What was verified

  • State checkpointed, encrypted, erasure-coded — AES-256-GCM, Reed-Solomon k=3 of n=6, under a 75-byte anchor.
  • Shards distributed to independent operators — one shard each to Evernode hosts in 6 countries (CA, GB, NZ, AU, US, IE).
  • Survived host loss — rebuilt from the 4 hosts that served (any 3 sufficient); the rest were unavailable.
  • Byte-exact — recovered canonical root == anchored root.

Scope & limitations — part of this certificate

Worked example, self-issued by the author — not a paid third-party audit. The hosts are independent by distinct operator, domain, and country; independence is not attested beyond that. The run used short paid EVR leases; 4 of 6 hosts served (one held a test contract, one was unreachable), which satisfies the k=3 threshold. Demo application state and a sample data key were used. The 75-byte anchor for this run is written on Xahau mainnet (tx 9D0D2679…C1924) as a public memo, so anyone can read it and reproduce the byte-exact match without trusting the author. "Byte-exact" means canonical-form exact.
